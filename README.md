# 🏙️ Citizen-Centric Complaint Platform

An AI-powered platform that allows citizens to report public issues such as road damage, water supply problems, garbage, and streetlight failures. It uses a **BiLSTM-based Machine Learning model** to automatically classify complaints and route them to the appropriate department.

## 🚀 Features

- 📝 Register complaints about public issues
- 🤖 AI-based complaint classification using BiLSTM
- 🏢 Automatic department assignment
- 📍 Real-time complaint tracking
- 🔄 Complaint status updates
- 📊 Improved transparency and efficient complaint management

## 🎯 Objective

To simplify the complaint registration process, reduce manual work, ensure complaints reach the correct department, and improve communication between citizens and government authorities.

## ⚙️ How It Works

1. Citizen submits a complaint.
2. The BiLSTM model analyzes the complaint text.
3. The complaint is classified into the appropriate category.
4. It is automatically assigned to the responsible department.
5. Citizens can track complaint status and updates.

## 🧠 Machine Learning

- **Model:** Bidirectional Long Short-Term Memory (BiLSTM)
- **Task:** Text Classification
- **Input:** Complaint text
- **Output:** Complaint category / responsible department

## 🌟 Benefits

- Faster complaint processing
- Automated complaint classification
- Reduced manual effort

- Better citizen engagement
- Efficient public service delivery
